# Yasmine Ben Slim — Portfolio

Portfolio statique prêt à être déployé sur **GitHub Pages**.

## Lancer en local

Depuis le dossier du projet :

```bash
python -m http.server 8000
```

Ouvrir ensuite : `http://localhost:8000`

## Déploiement recommandé — GitHub Pages

### Option idéale
Créer un repository public nommé :

`yasminebenslim.github.io`

Puis uploader **le contenu du dossier** directement à la racine du repository :

- `index.html`
- `styles.css`
- `script.js`
- `assets/`
- `site.webmanifest`
- `.nojekyll`

### Activer GitHub Pages

Dans GitHub :

**Settings → Pages**

- **Source**: `Deploy from a branch`
- **Branch**: `main`
- **Folder**: `/ (root)`

Le site sera ensuite publié sur :

`https://yasminebenslim.github.io`

## Publication sur LinkedIn

Ajouter l’URL du portfolio dans :

- **Contact info → Website**
- **Featured**
- Le CV / les candidatures
